# 🌐 Personal Portfolio with Admin Analytics Dashboard

A modern, fully responsive personal portfolio website built with **React**, **Vite**, and **Tailwind CSS**, featuring a secure admin dashboard with visitor analytics, JWT authentication, and real-time Telegram notifications.

## ✨ Features

### 👨‍💻 Portfolio

* Responsive modern UI

* Smooth scrolling and animations

### 🔐 Admin Dashboard

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/rajsharma331/portfolio.git
```

## Navigate into the project

```bash
cd portfolio
```

## Install dependencies

```bash
npm install
```

## Configure environment variables

Create a `.env` file:

```env
VITE_API_URL=YOUR_BACKEND_URL
```

## Start development server

```bash
npm run dev
```
